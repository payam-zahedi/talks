# From Review Bottleneck to Auto-Merge

flutterCon Berlin, 8 October 2026.

How our Flutter team uses AI for code review on GitHub, and which pull requests can merge without a human.

Slides: https://payam-zahedi.github.io/talks/fluttercon-2026-ai-code-review/

## Using the slides

- Arrow keys or space move through the slides. `?` lists all keys.
- To use them offline, download this folder and open `index.html` in a browser. The fonts come from Google Fonts, so the first load needs internet.
