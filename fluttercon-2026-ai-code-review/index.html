# Review learnings

Lessons from our past reviews. One line each: issue: rule [e.g. a reason it may be wrong].

 

- Missing dispose: a widget disposes the controllers it creates [e.g. a parent/provider creates them]

- Bloc to bloc communication: blocs talk through a repository, not to each other [e.g. the UI layer wires the two]

- Animation rebuilds everything: AnimatedBuilder passes the static part as child [e.g. all of it depends on the value]
