## Adding a talk

1. Make a folder named `<event>-<year>-<topic>`, in lowercase with hyphens. The name becomes part of the address.
2. Put the slides in it as `index.html`, with media in `assets/`. Paths in the HTML must be relative (`assets/x.png`, not `/assets/x.png`).
3. Add a short `README.md`, a row to the table above and a link in the root `index.html`.
4. Push to `main`. GitHub Pages publishes it in about a minute.
